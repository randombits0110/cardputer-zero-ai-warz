# Third-party license texts

Keep this directory with `LICENSE` and `THIRD_PARTY_NOTICES.txt` when distributing AI Wars.

The manifest records SHA-256 hashes and public source references. Full upstream files
are preserved as supplied; the manifest identifies the two full-license extracts and
the contributor-comment extracts. The Microsoft file is a project notice with official
links, rather than a replacement EULA.
