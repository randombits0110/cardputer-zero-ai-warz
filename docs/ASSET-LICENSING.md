# Asset licensing and provenance

This register describes the assets selected by the current packaging rules.
It does not independently establish ownership or clear third-party branding,
likeness, or other non-copyright rights.

| Assets | Documented basis |
| --- | --- |
| `assets/audio/intro.mp3` | Project-supplied MIT notice in `assets/audio/intro-LICENSE.txt`, also copied to `LICENSES/Intro-Music-MIT.txt`. |
| `assets/fonts/Montserrat-Bold.ttf` and `Montserrat-Medium.ttf` | SIL OFL 1.1; `LICENSES/Montserrat-Bundled-OFL.txt`. |
| Montserrat bitmap glyphs embedded in LVGL | LVGL's upstream Montserrat OFL notice in `LICENSES/Montserrat-LVGL-OFL.txt`. |
| Font Awesome 5 glyphs embedded in LVGL | Font-data OFL section of `LICENSES/FontAwesome5-LICENSE.txt`. |
| Windows simulator `assets/images/cp0-dark.png` and `cp0-light.png` | Both were verified byte-identical to the local CardputerZero Template copies. Preserve the template MIT notice in `LICENSES/CardputerZero-Template-MIT.txt`. |
| Game icon, intro, start-screen, arrivals, encounter, news, ending artwork, and documentation screenshots | Project-supplied artwork with no separate asset license found in the selected source files. The repository's main MIT license is the stated project license; the publisher must have the rights needed to apply it. |

The device's Noto Sans CJK system fonts are loaded from its existing installation
and are not bundled by these packaging rules. Additional unused fonts and artwork
originals in a development workspace are outside this register and should not be
added to a public archive without checking their own provenance and notices.

If game assets were generated by an external service, retain the relevant
generation/provenance records and confirm that service's applicable distribution
terms before publishing. No service-specific asset permission is inferred here.

The Windows simulator is a community application. Its code and asset notices do
not imply endorsement by M5Stack, Raspberry Pi, or any other named organization.
